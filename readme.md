# Word Autocomplete

A terminal-based word autocomplete engine written in **C**, using a **Trie (Prefix Tree)** data structure to efficiently store words and generate suggestions based on user input.

```text
|    2. application                              |
|    3. apply                                    |
|    4. appointment                              |
|                                                |
+------------------------------------------------+
```

## Features

- Fast prefix-based word searching using a Trie
- Multiple word suggestions for matching prefixes
- Terminal-based interface
- Written in C
- Efficient word insertion and lookup

## Data Structure

The autocomplete engine uses a **Trie**, where each node represents a character. Words with common prefixes share the same path.

For example:

```text
(root)
   |
   a
   |
   p
   |
   p
  / \
 l   o
 |   |
 e   i
     |
     n
     |
     t
     |
     m
     |
     e
     |
     n
     |
     t
```

This structure allows the program to find suggestions without scanning every word.

## Build

Make sure you have GCC or Clang and Make installed.

```bash
make
```

## Run

Run the executable generated by your Makefile.

```bash
./autocomplete
```
